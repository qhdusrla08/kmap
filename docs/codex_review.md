## 1. 사전 실험 요약

| 항목 | 내용 |
|---|---|
| 모델 | 고전 후보 생성(11×11 black-hat + 5×5 국소 최대, 최대 800개) → 17×17 패치 85개 특징 → RF(트리 100개, 깊이 16) / HGB(100회, 잎 15개). **고정 10×10 박스**, NMS IoU 0.2 |
| 영상본 | Raw(그레이), Mask(색상 마스크를 1px 팽창 후 중앙값으로 채움), Inpaint(같은 마스크, Telea r=3) |
| 분할 | 날짜 기준. 학습 06-22~06-29(294장, 881개), 검증 07-14~08-18(73장, 133개), 테스트 08-19~09-22(133장, 133개, **모두 1객체**) |
| 평가 | IoU≥0.5 일대일 매칭, 자체 구현 AP(COCO 101점 방식과 다름), 검증 F1 최대가 되는 임계값 |
| 주요 수치 (테스트) | 마킹만 쓰는 탐지기 P=R=0.970 / Raw HGB R=0.812 / **Inpaint HGB R=0.985, AP50=0.985, AP75=0.32, AP50:95=0.447** / Inpaint RF AP50=0.980이지만 R=0.143 (임계값 이식 실패) |
| 교란 실험 | 팽창 2/3px에서는 거의 유지됨. 무작위 decoy 3개를 넣으면 소폭 저하. 마킹 내부까지 지우면 R=0.015. **3×3 중앙값 필터를 쓰면 R=0** |
| 중첩군 (06-24 별도 평가) | 마킹과 겹친 객체는 IoU 기준 R=0.379이지만 중심은 66/66 탐지 → 고정 박스 크기가 병목 |

## 2. 점검 6항목 판정

| # | 항목 | 판정 | 근거 |
|---|---|---|---|
| 1 | **색상 사각형 누수** | Raw는 **무효**. Mask와 Inpaint는 **조건부 참고(최종 근거로 쓰지 않음)** | Raw는 마킹이 남아 있어 무효입니다. Inpaint는 색상 마스크를 1px 팽창했는데, 실측한 **후광은 약 3px까지 이어져 일부가 남았을 수 있습니다**(`data_spec.md` §3.1). 학습에 decoy를 쓰지 않았고 테스트 decoy도 3개뿐입니다. Mask는 중앙값 사각형이 새 단서가 됩니다(Codex 본인도 인정). 공지의 추가 안내가 반영되기 전에 진행된 실험입니다 |
| 2 | 가이드북 파이프라인 답습 | **통과** | 무작위 8:2 분할 없음, `last*.pt` 사용 없음, 가이드북 수치와 비교 없음 |
| 3 | 정답 기준 | **통과** | 주 TXT 500개를 정답으로 고정. TXT 없음과 빈 XML을 음성으로 쓰지 않음. 충돌 3개와 추가 12개 stem 제외 |
| 4 | 데이터 분할 누수 | **대체로 통과, 한계 있음** | 날짜 단위(전 호기 공통)라 연속촬영 누수는 없습니다. 다만 학습은 3띠, 테스트는 1띠라 **분포가 이동**하고, 그 결과 RF 임계값이 붕괴했습니다. 테스트를 이미 여러 실험으로 열람했으므로 미접촉 테스트가 아닙니다 |
| 5 | 재현성 | **부분 통과** | seed 고정, 단일 명령 `reproduce.py`, 환경 JSON, 해시 manifest가 있습니다. 반면 Windows 경로와 맑은 고딕에 의존합니다. **README와 evidence에 사용자명이 든 절대경로가 있어 블라인드 규정에 위험합니다** |
| 6 | 외부 데이터·사전학습 가중치 | **통과(사용 없음)** | CPU 전용 sklearn 모델입니다 |

## 3. 재사용 / 폐기

| 구분 | 항목 | 이유 |
|---|---|---|
| 재사용 | 픽셀 해시 중복, TXT 충돌, XML 감사 로직 | 실측과 일치합니다. `src/data/index.py`에 같은 기능을 다시 구현했습니다 |
| 재사용 (개선) | 후보 생성 + HGB 베이스라인 (`work/experiments.py`의 `candidates()`, `eval_pred()`, `nms()`) | 마킹 없이도 신호가 있음을 보여 준 해석 가능한 베이스라인입니다. **가변 박스**(국소 블롭)와 공통 평가 모듈로 개선하고, 새 전처리(2px 팽창, decoy)로 다시 학습합니다 |
| 재사용 | 교란 실험 구성 (`work/robustness_hgb.py`) | 팽창 폭, decoy, 내부 삭제, 중앙값 필터 실험을 T3·T4·T8에 반영합니다 |
| 재사용 | 마킹만 쓰는 누수 진단기, IoU별 AP, 날짜 군집 부트스트랩 | 누수 크기(T2)와 불확실성 보고에 씁니다 |
| 폐기 | Raw·Mask 결과 수치 | 누수 또는 흔적 지름길 때문입니다 |
| 폐기 | Codex 수치를 최종 성능으로 인용하는 것 | 전처리, 분할, 평가 구현이 다릅니다. 이 프로젝트의 분할에서 다시 측정합니다 |
| 폐기 | Windows 경로·폰트 설정, `evidence/`의 절대경로 | 이식성과 블라인드 규정 때문입니다. 제출물에 포함하지 않습니다 |
| 교훈 | 중앙값 필터 같은 점 신호 훼손 전처리 금지 | 코어가 2–4px입니다(`data_spec.md` §3.2) |
| 교훈 | 고정 박스로는 AP75가 낮음 | 가변 박스 회귀가 필요합니다. 박스 관례의 IoU 상한도 분석합니다 |
| 교훈 | 검증에서 정한 임계값이 다른 날짜로 이식되지 않음 | 층화 분할, OOF 기반 보정, 1객체 하위셋 지표를 씁니다 |
