# external_data.md — 외부 데이터·가중치·자료 기록

- 공지: 출제 데이터 외의 데이터를 쓸 때는 **활용 사유, 활용 방법, 출처**를 결과보고서에 적어야 하며, 공개에 문제가 없는 데이터만 사용합니다.
- 사전학습 가중치도 외부 데이터 활용으로 취급합니다(CLAUDE.md §5).
- 항목을 추가할 때 즉시 이 문서에 기록합니다.

## 사용하지 않는 자원

- 데이터셋에 포함된 가이드북 가중치 `last*.pt`: 색상 표시가 남은 이미지로 학습되었을 수 있어 사용하지 않습니다.
- 다른 외부 영상 데이터셋: 사용하지 않습니다.
