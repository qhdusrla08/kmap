## □ 제1장. 데이터 이해 및 진단〔15점〕

&nbsp;◦ **데이터가 나타내는 공정 상태**

&nbsp;&nbsp;&nbsp;- 식품제조업체 H사 분말유크림 포장공정의 마지막 단계인 X-ray 이물검사 영상임. 미검(이물이 있는데 통과)은 곧 시장 유출로 이어지므로 Recall을 최우선으로 둠

&nbsp;&nbsp;&nbsp;- 1·2·3호기 검출기(시리얼 SN77128·SN77127·SN12053)의 SD 카드에 **장비가 불량(NG)으로 판정한 제품만** 자동 저장된 기록임. 기간은 2020-06-22 ~ 09-22, 양품(OK) 영상은 없음

&nbsp;&nbsp;&nbsp;- 영상 1장은 제품 1개의 투과 영상임. 같은 호기에서 3~4초 간격으로 약 5장씩 연속 저장된 묶음이 547개임

&nbsp;&nbsp;&nbsp;- 촬영의 90.3%가 0·4·8·12·16·20시에 몰리고, 같은 초에 여러 호기가 찍힌 경우가 69건임. 영상 속 제품은 어두운 띠 1줄 또는 3줄을 담고 있고, 이물은 항상 띠 한쪽 끝에서 안쪽 약 7–16px 지점에 있음〔그림 1-1〕

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\* 해석(가설): 4시간 주기 **정기 감도점검(시험편 통과) 세션**일 가능성이 높음. 같은 물리 시험편을 반복 촬영했을 수 있으므로 어떤 분할로도 ‘새로운 이물’에 대한 일반화는 보장되지 않음을 전제로 분석함

&nbsp;◦ **장비 색상 표시의 진단 — 가장 큰 위험(표시 누수, label leakage)**

&nbsp;&nbsp;&nbsp;- 표시가 있는 영상은 **2,809 / 2,809장(100%)**임. 표시는 한 변 18–22px, 두께 2px의 정사각 테두리이고 이미지당 최대 3개임(3호기는 색이 다른 테두리가 겹침)

&nbsp;&nbsp;&nbsp;- TXT 객체 중심의 **1,145 / 1,147(99.8%)이 표시 안**에 있고, 중심 편차의 표준편차는 약 0.9px임 → TXT는 장비 표시를 옮겨 그린 것임〔그림 1-2〕

## □ 제4장. 현장 활용방안〔10점〕

&nbsp;◦ **적용 위치: 최종검사 단계의 2차 판정기**

&nbsp;&nbsp;&nbsp;- 흐름: 기존 X-ray 검출기(1차 판정) → NG 영상 → **AI 판정기** → 통과(출하) / 재검사(작업자 육안·재투과) / 배출(불량 격리)

&nbsp;&nbsp;&nbsp;- 현재 데이터로 검증 가능한 범위는 장비 NG 영상의 2차 판정임. 장비 과검을 AI가 통과시켜 이중·삼중 검사 물량을 줄이고, 이물이 확실한 영상은 바로 배출함

&nbsp;&nbsp;&nbsp;- 장비 OK 영상까지 AI가 보면 장비 미검을 보완할 수 있으나, OK 영상이 없어 미검 감소 효과는 측정할 수 없음 → 도입 시 OK 영상 수집 단계를 둠

&nbsp;&nbsp;&nbsp;- 실제 라인에서는 장비 표시가 없는 원영상을 받는 것이 바람직함. 표시가 있는 영상이면 본 전처리(팔레트 마스크 + 2px 팽창 + telea_n)를 그대로 적용함

> 〔그림 4-3〕 통과 임계값 위치별 통과 미검과 재검사 비용(dev OOF, 원시 점수 로그 축). 파랑 = 통과로 판정된 1객체 양성 영상 비율(초록 점선 = 3호기), 주황 = 재검사로 보내지는 대리 음성 비율. 음영 = 시뮬레이션 분할별로 각 규칙이 고른 임계값 범위(빨강 R0, 초록 R4), 점선 = 사전 t_low(원시 점수 0.554 = 보정 확률 0.947)와 최종 t_low(마진 규칙 R1, 원시 점수 0.359 = 보정 확률 0.833). R1의 분할별 임계값은 원시 점수 0.10–0.62로 넓게 흩어져 음영으로 표시하지 않음. 0.1–0.5 구간은 비용이 거의 평평해 양성 쪽 안전 마진을 둘 수 있음

&nbsp;&nbsp;&nbsp;- dev 안 재현과 규칙 비교: 테스트를 쓰지 않고, 규칙 후보와 선택 기준을 실행 전에 고정함

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\* LOFO: fold 하나를 빼고 나머지 OOF로 규칙을 정해 뺀 fold에 적용 → 날짜·모집단 분포 이동(population shift) 반영

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;\* 중첩 학습: 2개 fold로 학습한 안쪽 모델(6개 추가 학습)의 OOF로 규칙을 정하고, 3개 fold로 학습한 모델에 적용 → 실제 절차(fold 모델 → 전체 재학습 모델)와 같은 배포 모델 이동까지 반영. 1객체 영상이 fold 2·3에만 있어 바깥 fold 2·3만 수행해도 1객체 115장 전부를 다룸(대리 음성 분모는 LOFO 400장, 중첩 188장)

## □ 제5장. 창의성 및 차별성〔10점〕

| 차별화 요소 | 기여(제2·3장 결과와의 연결) |
|---|---|
| **팔레트 기반 정확 검출 + 후광 발견** | 채널 임계값 없이 손실 없이 표시를 찾고, 테두리 바깥 약 3px의 후광을 실측해 ‘테두리만 지우면 흔적이 남는다’는 사실을 정량화함 → 2px 팽창 근거(제1장) |
| **흔적-이물 탈상관 학습** | 모조 표시(흔적 O·이물 X), 투과율 이식(이물 O·흔적 X), 흔적 음성 샘플(실제 흔적 O·이물 X)을 짝으로 넣음. 같은 측정 방식(HGB, 박스 안쪽만 삭제)에서 이물 삭제 위치 오검출률: 전처리만 5–40% → 모조 표시·이식 13.2% → 흔적 음성 샘플 추가 0.2%. F1은 0.974 → 0.980 → 0.979로 유지(HGB, ablation 평가 영상 기준이라 제2장 M0 0.986과 측정 조건이 다름, 흔적 음성 샘플은 5×5 삭제판) |
| **사전 고정 기준의 누수 반증 시험 묶음(T1–T8)** | 표시 없는 영상이 하나도 없어 ‘표시 유무 비교’를 할 수 없는 상황을 대체함. T1 불합격도 그대로 보고하고 구조 교락으로 진단함. T7로 모델이 코어를 본다는 직접 증거를 얻음(제2장) |
| **표시만 쓰는 탐지기와 원본 학습 대조군** | 영상을 보지 않고 F1 0.94, 원본 학습 모델은 표시를 지우면 AP50 0.974 → 0.699 → ‘높은 점수 ≠ 이물 학습’을 수치로 보임 |
| **음성 0장 상황의 대리 음성** | 같은 제품 배경의 실제 픽셀(bg_max)로 이미지 FP율을 추정하고 이물 혼입률별 운영표로 환산함(제4장) |

| **보정 + 3구간 + 불확실성** | ECE 0.216 → 0.002, 최종검사 맥락의 비대칭 기준(통과는 미검 억제, 배출은 대리 음성 0건), TTA 불확실성으로 점수가 사전 t_low(0.947)보다 낮은 객체 20개(IoU 0.5 매칭 점수 기준) 중 7개를 재검사로 회수(대리 음성 추가 재검사 0.5%, 사전 규칙 기준. 현행 마진 규칙에서는 안전 장치로 유지) |
| **임계값 이식 검증(중첩 시뮬레이션)** | 테스트 실패를 테스트 재사용 없이 dev에서 재현(사전 규칙 3호기 1객체 12/45 통과)하고, 사전 고정 기준으로 규칙을 비교해 통과 미검을 12 → 3으로 줄인 마진 규칙을 채택. 배포 모델 이동을 미라벨 영상으로 따로 확인(제4장) |
| **모니터링 지표 정정과 원인 분리** | 상위 3개 박스 집계의 착시(‘검출 마진 급락’)를 찾아 정정하고, 이물 대비·영상 품질(장비)과 점수 분포(판정)를 분리해 감시하는 방식을 제안. 3호기 문제는 장비 열화가 아니라 제품 전환 조합 효과임을 보임(제3·4장) |
| **도메인 해석** | 촬영 시각·연속촬영·띠 끝 배치에서 감도점검 세션 가설을 세움 → 날짜 그룹 분할, 일반화 한계 서술, 감도 모니터링 제안에 반영 |
| **선택 편향 차단** | early stopping 없음, fold 마지막 가중치로 OOF, 임계값·보정은 OOF로만, 테스트는 한 번만, 사전학습과 scratch 비교 |

&nbsp;&nbsp;&nbsp;- 데이터 수준 흔적 판별 시험(T1)은 사전 기준에 불합격함(구조 교락) → 모델 수준 시험(T3–T7)으로 대체해 검증함

&nbsp;&nbsp;&nbsp;- 유효 깊이 약 21 gray(α = 0.45) 아래의 저대비 이물은 recall이 급락함(통제 스트레스 기준)
